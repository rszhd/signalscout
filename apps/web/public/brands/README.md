# Brand icons

Downloaded from official websites on 2026-09-06, `instagram.png`,
`apify.png` and `socialdata.png` on 2026-09-07, the model providers on
2026-09-10, and `deepseek.png` on 2026-09-11. Original favicon files, used to
identify the provider or platform; their respective owners retain rights to
their logos and trademarks. These assets are not covered by the project’s
Apache-2.0 license. Served locally; the UI makes no external favicon requests.

`openai.png` is the OpenAI GitHub organisation avatar, because openai.com
refuses a direct favicon request from this network.

`deepseek.png` is the site's own `favicon.ico` resized to 64 pixels. The
original is 225 pixels square and 205 KB, which is five times the largest file
here for an icon the UI draws at 20.
