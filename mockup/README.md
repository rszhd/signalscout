# Signalbox interactive mockup

This is a dependency-free HTML, CSS, and JavaScript mockup for the open-source AI intent-monitoring product.

## Open it locally

Double-click `index.html`, or serve this folder with any static web server.

For example:

```bash
npx serve .
```

The mock data and interactions live in `app.js`. Styling is in `styles.css`.

## Included views

- Intent inbox and match details
- Match filtering, saving, and feedback
- AI reply-drafting modal
- Monitor creation wizard
- Monitor management
- Reddit, X, and AI-provider connections
- Workspace settings

`Signalbox` is a provisional product name used only for this mockup.
