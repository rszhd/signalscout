How did you generate your initramfs? Does the LiveGUI work if you use nomodeset with it?

If you use dracut (especially with full disk encryption), then a common issue is that you forgot to add your GPU driver kernel module into dracut's add_drivers, e.g.

Code: Select all

add_drivers+=" i915 "
(i915 is for intel GPUs, check your lsmod output and figure out which module you need, then regenerate your initramfs.)
Dracut's documentation is a bit confusing, so I ran into the same issue before.
