    Dedicated IP on Shared Servers

    I am using reseller hosting. I have hundred of customers. Each shared same IP on the server that provided by reseller hosting provider. Some times IP reputation can be decrease because of some accounts compromised and cuused spam (even IP removed from blacklist). So emails can be arrive to bulk/junk box of some recipients.

    My question is if we buy a dedicated IP for our reseller account or any resold account, it can be resolve this problem or isolate us and our customers from other resellers on the server?

    Yes, usually getting a dedicated IP number works like that.
    Depending on who you have the reseller account with, you might be able to allocate that dedicated IP to some customer accounts, not necessarily all of them.

    Just be aware if that dedicated IP gets blacklisted, then every account using it becomes affected.
    A dedicated IP is not expensive. If you have hundreds of accounts, you might want 2 or 3 dedicated IPs. Maybe keeping one in reserve in case one gets blacklisted.
    It might be a case of try it and find out.

    Many providers will use a relay service like MailChannels, MailBaby, SpamExperts, etc. and the emails will be sent from an IP address in a pool owned by said relay service, rather than your account's IP address - in which case, a dedicated IP won't achieve anything.

    Also worth noting that even if that's not the case and you indeed get a dedicated IP, one of your customers could still get hacked or cause abuse issues and blacklisted IP space for your other customers.

    So I don't think you'll gain anything by going down the dedicated IP path.

    The catch with KYC is that a genuine customer's mailbox can still get hacked.

    I'd ask the host what outgoing mail limits they set per domain and how they flag sudden spikes. A dedicated IP won't remove that risk if all your own customers share it.
