      Truncate your cache and cacheevent tables. You can do this in whatever tool you use to manage your database. Examples would be Adminer, phpMyAdmin, HeidiSQL, and DBeaver.

      Code:
      truncate table vb_cache;
truncate table vb_cacheevent;
      Make sure that the cacheid field in the vb_cache table is a varbinary(64) field. It should not be an integer or double field.
